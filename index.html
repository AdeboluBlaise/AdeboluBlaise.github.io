Projects

Seven analyses in R and Python, from time series of Nigerian food prices to classification models. Hover over a figure, or tap it, to watch the method at work.

Food prices in Nigeria: trends and a VAR model

Monthly market prices for nine staples from 2012 to 2022. I interpolated missing months, checked for outliers and made each series stationary with ADF tests and differencing, then fitted a vector autoregression and ran Granger causality tests to see which prices lead the others.

R: ADF test, differencing, VAR, Granger causality

Code and plots on GitHub

×3.6rise in the price of a 50 kg bag of imported rice, 2012 to 2022

Hospital resources and patient outcomes

A descriptive and inferential study of 35 hospitals: beds, staff, deaths and stroke outcomes. Shapiro–Wilk tests showed the variables were not normally distributed, so I used Spearman correlations and Wilcoxon rank-sum tests, alongside t-tests and confidence intervals for stroke admissions.

R: Shapiro–Wilk, Spearman correlation, Wilcoxon rank-sum, t-test, confidence intervals

Code and plots on GitHub

ρ = 0.85rank correlation between hospital beds and staff

Governance, corruption and economic growth

885 country-years from the Quality of Government dataset, 2012 to 2021. I modelled GDP growth on governance indicators with multiple regression, dropped the corruption index after variance inflation factors flagged collinearity, and checked the model with Breusch–Pagan, Shapiro–Wilk and Durbin–Watson tests.

R: multiple regression, VIF, residual diagnostics

Code on GitHub

r = 0.95correlation between rule of law and corruption perception, the collinearity the model had to handle

Predicting a phone’s price band

2,000 phones described by 20 specifications, in four price bands. I capped outliers, ranked features with a random forest (RAM carried half the importance), then compared a decision tree, k-nearest neighbours and a neural network on a held-out 20%.

Python: scikit-learn, random forest, decision tree, KNN, MLP

Notebook on GitHub

96.5%test accuracy for the neural network, against 83% for a decision tree and 62% for KNN

Customer satisfaction and segmentation

About 8,000 order records merged from two files. I modelled the satisfaction rate with linear regression, checked it on held-out orders, then segmented customers with k-means, choosing the number of clusters by silhouette score.

Python: pandas, statsmodels OLS, scikit-learn k-means

Notebook on GitHub

R² = 0.97for the satisfaction model on held-out orders

Franchise profit with tree models

Profit data for 100 café, pizza and burger franchises in two cities. I encoded business type and location, fitted a decision tree and a random forest, and used feature importance to show what drives profit.

Python: scikit-learn decision tree and random forest regressors

Notebook on GitHub

R² = 0.91for the random forest on held-out franchises

Segmenting mall shoppers

200 shoppers described by age, income and spending score. After removing the two highest-income outliers I chose the number of clusters with the elbow method and grouped the shoppers with k-means into segments a marketing team can target.

Python: seaborn, scikit-learn k-means, Yellowbrick elbow method

Notebook on GitHub

k = 4shopper segments, chosen by the elbow method
